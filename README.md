# 🃏 Cards — CSS & HTML

A pure **HTML & CSS** project showcasing stylized character cards featuring iconic anime heroes — Naruto Uzumaki, Deku, and Monkey D. Luffy — each with custom image backgrounds and clean bordered layouts.

## ✨ Features

- 🎴 **Three anime character cards** with individual custom backgrounds
- 🖼️ **Background images** using removed-background PNGs for a clean look
- 🎨 **CSS-heavy styling** with borders, layout, and card design
- ⚡ No JavaScript — pure HTML & CSS

## 🛠️ Built With

- **HTML5** — Card structure and layout
- **CSS3** — Card styling, backgrounds, and borders

## 📁 Project Structure

```
cards_css_and_html/
├── index.html                        # Card layout markup
├── style.css                         # All card styles
├── image-removebg-preview.png        # Character background image 1
├── image-removebg-preview (2).png    # Character background image 2
└── README.md                         # Project documentation
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/illusionoftalha/cards_css_and_html.git
   ```
2. Open `index.html` in your browser — no build step needed.
